# Contributing

This repository is a restored archive of a September 2020 school project. The
application code is preserved in its original form on purpose.

- Bug reports and questions are welcome through GitHub issues.
- Application code changes are accepted only when they fix a real defect
  without reshaping the original architecture; large refactors go against the
  point of an archive.
- Repository tooling (CI, docs, config files) can be modernized freely.
- Keep commit messages conventional: `feat:`, `fix:`, `docs:`, `chore:`, `ci:`.

## Local development

The stack targets PHP 7.4 with the `intl` extension plus MySQL / MariaDB. The
README "Getting started" section covers the full setup.
