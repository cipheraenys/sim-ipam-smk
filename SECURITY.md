# Security policy

## Supported versions

This is an archived educational project. The framework is intentionally
pinned to CodeIgniter 4.0.5, which carries known and unfixed upstream security
advisories. Do not deploy this application to the public internet.

## Reporting a vulnerability

Open a private security advisory through the repository Security tab or
contact the maintainer. Given the archive status and the pinned dependencies,
findings will be documented rather than patched in place.
